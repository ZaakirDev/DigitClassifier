# DigitClassifier

## Usage:

1. To install all the python libraries, open the terminal and run `pip install -r requirements` if you are on windows and `pip3 install -r requirements` on mac/linux
2. Extract `Dataset.zip` in `/DataFiles` to get the testing and training csv files. (These are included in `.gitignore` due to large size)
3. To run the model with the testing procedure, run `Model.ipynb`
4. To run the model training procedure seperately, `run Model.py` (NOTE: THE MODEL TRAINED BY THIS PROGRAM WILL BE STORED AND USED BY THE DRAWING APPLICATION)
5. To run the drawing application, run `DrawingApplication.py`

### Note: `image_converter.py` is just a simple program I made to conveniently convert the csv files into images for the user to use with the drawing application. The folder of images it generates is included in `.gitignore`.
